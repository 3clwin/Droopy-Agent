# Client design system

Bind to the client's tokens after onboarding. Do not invent a brand.

At first run, Droopy Agent records where specs live (Figma, Mural, Confluence, FigJam, or none). Use those links and whatever design-system documentation the operator provides. Until then:

- Do not invent colors, type, spacing, or component names.
- Prefer the ticket's acceptance criteria and any linked design node.
- If no design link exists, judge consistency against the live product and general accessibility — not a fictional system.
